Application behaviour checkpoint

The independent regression suite now covers shared state across components, keyed filtering/sorting identity, and mixing Rivet with native DOM nodes and event listeners. The data-table fixture is intentionally built from public primitives rather than private runtime hooks.

Implemented

Optional hypermedia core

request(), explicit swaps, native lifecycle events, declarative r-get/r-post, progressive forms, and explicit re-enhancement are covered by the independent regression suite. Client-side routing/history remains deliberately out of scope.

Certified

Real-browser regression lane

The independent suite now includes a Chromium-backed lane for browser semantics the lightweight DOM harness should not fake: native FormData, requestSubmit(), real HTML parsing, and bubbling lifecycle CustomEvents. The fast default suite remains lightweight.
