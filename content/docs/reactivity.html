Reactivity

Three primitives.
No hidden lifecycle.

Rivet's reactive core currently consists of state(), computed(), and effect().

state(initial)

const count = state(0);
count.value = 4;
count.value++;

Reads are tracked while an observer is active. Writes notify current dependants synchronously.

computed(fn)

const doubled = computed(() => count.value * 2);
console.log(doubled.value);

Computed cells are lazy and cached until a dependency invalidates them.

effect(fn)

const stop = effect(() => {
    console.log(count.value);
});

stop();

An effect tracks the state it reads and returns a disposer. Dependencies are recalculated each run.
