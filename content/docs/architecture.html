Native interoperability

node.textContent = "plain DOM";

mount("#widget", html`<p>Rivet + ${node}</p>`);
node.addEventListener("click", handleClick);

Rivet deliberately does not wrap DOM nodes, events, fetch, forms, or platform APIs. A mounted widget owns the target you give it, not the surrounding document.

Hypermedia is being earned, not assumed

The CP46 use-case audit found a narrow area where declarative behaviour is genuinely clearer: server-rendered fragment requests followed by an explicit DOM target/swap. More ambitious concerns such as confirmation DSLs, polling, and history/navigation remain deferred until real applications justify them.

Source readability gates

The runtime source is checked for import cycles and keeps each module under a 350-line review threshold. The threshold is an alarm, not a style theorem: when a module trips it, the preferred repair is a concrete narrow subsystem rather than a generic abstraction layer.

npm run readability:check

AI-DX task suite

The task suite is model-neutral and records raw outcomes instead of collapsing them into a subjective score. External agents are intentionally not invoked by the framework test suite.
