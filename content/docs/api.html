API reference

The public surface,
kept intentionally small.

This reference lists APIs implemented in Rivet today. Planned APIs are not presented as available.

mount(target, template)

Replaces the target element's children with rendered Rivet output and returns an unmount function that releases Rivet-owned resources.

state(initial)

Creates a mutable reactive cell. Read and write through .value.

const count = state(0);
count.value++;

computed(fn)

Creates a lazy cached reactive cell derived from other reactive reads.

const doubled = computed(() => count.value * 2);

effect(fn)

Runs immediately, tracks reactive reads, reruns synchronously when dependencies change, and returns a disposer.

const stop = effect(() => console.log(count.value));
stop();

html`...`

Creates a Rivet template result using valid JavaScript tagged-template syntax.

render(template)

Turns a Rivet template result into a native DocumentFragment.

onCleanup(fn)

Returns a renderable cleanup token. The callback runs when the containing rendered subtree is disposed.

html`${onCleanup(() => clearInterval(timer))}<p>...</p>`

ref=${callback}

Calls the callback with the native DOM element during rendering and with null when that element is disposed.

html`<input ref=${node => { input = node; }}>`

Function components

Any ordinary function that returns an html template result can be used as a component. Rivet adds no registration API.

key(id, value)

Marks one renderable list entry with explicit identity. Reactive keyed arrays preserve existing DOM nodes across reordering. Keys must be non-null and unique within the list.

rows.value.map(row => key(row.id, Row(row)))

request(url, options?)

Runs a native fetch request and resolves to { response, html }. Native fetch options are forwarded unchanged. Non-OK responses throw RequestError containing response, status, and the returned HTML text.
