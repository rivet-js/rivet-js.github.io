Components

Functions.
That's the model.

A Rivet component is an ordinary JavaScript function that returns a Rivet html result. There is no component base class, registration step, hook ordering rule, or special invocation syntax.

Define a component

export function Counter() {
    const count = state(0);

    return html`
        <button onclick=${() => count.value++}>
            Count: ${count}
        </button>
    `;
}

Use it like a function

mount("#app", Counter());

const page = html`
    <main>${Counter()}</main>
`;

Calling a component returns renderable output. Ordinary JavaScript remains the composition mechanism.

Props are plain objects

function Greeting({ name, punctuation = "!" }) {
    return html`<p>Hello ${name}${punctuation}</p>`;
}

Greeting({ name: "Rivet" });

Props are normal function arguments. Rivet does not create component instances, prop descriptors, or a separate props API. Reactive cells can be passed directly when the child should observe them.

Children are just another prop

function Panel({ children }) {
    return html`<section>${children}</section>`;
}

Panel({
    children: html`
        <h2>Rivet</h2>
        <p>Ordinary composition.</p>
    `
});

Rivet does not introduce a slot language for basic composition. Pass renderable output through a normal children property and compose components with ordinary function calls. Multiple children can be grouped in an html template.

Own resource cleanup explicitly

function Clock() {
    const timer = setInterval(tick, 1000);

    return html`
        ${onCleanup(() => clearInterval(timer))}
        <p>${time}</p>
    `;
}

onCleanup(fn) ties an arbitrary resource to the lifetime of the rendered subtree. It runs when that subtree is replaced or unmounted. Use it only for resources ordinary DOM cleanup does not already cover.

Use native DOM refs when necessary

let input;

const view = html`
    <input ref=${node => { input = node; }}>
`;

A ref callback receives the native element directly and receives null when the element is disposed. Rivet does not wrap DOM nodes in a ref object.
