Getting started

Start with JavaScript.
Add only what you need.

Rivet's core is plain ES modules. There is no required compiler or application scaffold.

Install

npm install rivet

During early development Rivet is not yet published. Work directly from the repository package.

Import

import { state, computed, effect, html, render } from "rivet";

Create state

const count = state(0);
count.value++;

Reactive state is deliberately explicit. A state cell behaves like a small object whose .value is tracked.
