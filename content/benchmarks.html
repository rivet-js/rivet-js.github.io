The measurement uses Rivet's deterministic conservative minifier. If canonical release bundling changes, the gate should move to the release artifact rather than pretending these numbers are directly comparable to production bundles from other frameworks.

AI-DX methodology

Rivet now ships five repeatable agent tasks covering state, derived values, function components, keyed identity, and async saves. Runs should record first-attempt correctness, repair iterations, changed files, unnecessary edits, and token counts where the agent exposes them.

No aggregate “AI score” is published yet. Results will only be compared when agents receive the same task fixture, public documentation, and acceptance tests.

Competing approaches

For a one-off counter, vanilla JavaScript is often the simpler choice. For repeated server-fragment interactions, declarative hypermedia can remove listener/fetch/swap boilerplate. Rivet does not currently publish React/Vue/Svelte performance comparisons because fair results require pinned idiomatic implementations and equivalent browser workloads.
