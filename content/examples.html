Async interaction

Use the platform

const status = state("Idle");
let activeRequest;

async function load() {
    activeRequest?.abort();
    activeRequest = new AbortController();
    status.value = "Loading…";

    try {
        const response = await fetch("/data", { signal: activeRequest.signal });
        if (!response.ok) throw new Error(`Request failed (${response.status})`);
        status.value = "Ready";
    } catch (error) {
        if (error.name !== "AbortError") status.value = "Error";
    }
}

Rivet does not need an async abstraction for ordinary loading, errors, cancellation, or fetch. Reactive cells hold UI state while JavaScript does the work.
