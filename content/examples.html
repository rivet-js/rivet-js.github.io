The first Rivet.

A complete counter using the currently implemented public API.

import { state, html, render } from "rivet";

const count = state(0);
const view = html`
    <button onclick=${() => count.value++}>
        Count: ${count}
    </button>
`;

document.querySelector("#app").append(render(view));
Why .value?

It keeps reactive reads and writes explicit and allows Rivet to remain valid JavaScript with no mandatory compiler transform.
